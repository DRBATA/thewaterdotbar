# Archived Chat System

This folder contains the original Water Bar chat system that was replaced with the LiveKit avatar integration.

## Files Archived:
- `virtual-barista-chat.tsx` - Original React chat component with popup UI
- `chat-api-route.ts` - Original API route with hydration calculations and Supabase integration

## Date Archived: 
January 26, 2025

## Reason for Archive:
Replaced with LiveKit education frontend architecture for real-time avatar interaction with voice, video, and enhanced user experience.

## Recovery:
If needed, these files can be restored by copying them back to their original locations:
- `virtual-barista-chat.tsx` → `components/`
- `chat-api-route.ts` → `app/api/chat/route.ts`

## Original Features:
- Text-based chat with hydration coach AI
- Personalized hydration calculations based on user profile
- Product recommendations with discount codes
- Profile storage via Dexie (client-side database)
- Integration with Supabase for menu data and user profiles
